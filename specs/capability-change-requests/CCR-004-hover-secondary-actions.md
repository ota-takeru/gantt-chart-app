## Capability Change Request: CCR-004

- Affected capability/version: `task-detail-disclosure` / 1.0
- Why the locked contract is insufficient: The current contract allows hover to paint a preview but reserves secondary actions for the stable selection. The requested interaction requires task actions such as memo, add-child, and delete to become visible and pointer-operable when their row is hovered, without first selecting the row.
- Proposed semantic change: Create `task-detail-disclosure` 1.1. Pointer hover may transiently expose that row's secondary actions for pointer use. Hover must remain presentation-only: it must not create, replace, or clear the stable selection; must not reveal selection-only task details; must not enter the actions into sequential keyboard navigation; and must not change row or primary-control geometry. Leaving the row hides the transient actions unless the row is selected or contains focus.
- Affected scenarios/states/errors/invariants: Extend S4 to allow transient action exposure while preserving the stable selection. Replace the 1.0 invariant that only the stable selection exposes secondary actions with a narrower rule: selection-only information is exclusive to the stable selection, while secondary actions may be exposed by stable selection, focus, or transient row hover. States and errors remain unchanged because hover is not a capability state transition.
- Existing and new tests: Preserve all headless transition/projection tests, including hover causing no state transition. Supersede the UI assertion that a hovered resting row's actions have `pointer-events: none`; add interaction coverage that hover exposes only that row's actions, does not change `data-disclosure-state`, does not reveal selection-only details, and restores the resting action state on pointer leave. Retain geometry, focus, keyboard-order, dense-fixture, and sole-stable-selection coverage.
- Compatibility or migration impact: UI-only successor behavior. No persistence, task data, API, Rust core, revision, history, undo, or migration impact.
- Requested authorization: Authorize creation and lock of `task-detail-disclosure` 1.1, preservation of 1.0 as historical evidence, and the narrowly scoped UI test/CSS updates described above.
- Authorization: authorized by the user's explicit request on 2026-08-30 to expose task actions on row hover while removing the visible lower metadata line.
