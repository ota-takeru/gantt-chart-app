## Capability Change Request: CCR-005

- Affected capability/version: `task-memo-live-markdown` / 1.0
- Why the locked contract is insufficient: Version 1.0 requires delimiters for the active construct to be visually exposed. In the shipped editor this leaves raw Markdown such as `>` visible while typing and makes the editor feel like source plus preview instead of one live-rendered surface. The editor theme is also fixed to CodeMirror's light mode, so focus and selection paint do not integrate with the application's OS-selected dark theme.
- Proposed semantic change: Create `task-memo-live-markdown` 1.1 with an opt-in `always-concealed` delimiter policy. Complete supported constructs remain directly editable from their exact source positions, but their Markdown delimiters remain visually concealed even when the caret intersects the construct. Preserve the 1.0 active-exposed policy as the default compatibility behavior. Make editor chrome, focus, caret, selection, semantic paint, and concealment follow the application's light/dark tokens without adding a separate theme state.
- Affected scenarios/states/errors/invariants: Replace S2 for the new policy so active constructs retain exact editable source without visually revealing complete delimiters. Add a theme-adaptation scenario. Preserve incomplete/unsupported-source recovery, IME safety, UTF-16 positions, persistence boundaries, and all task memo states/errors.
- Existing and new tests: Keep all 1.0 contract tests unchanged. Add 1.1 contract coverage for complete active delimiters remaining concealed under the new policy, plus editor integration coverage for no exposed delimiters and light/dark-compatible theme wiring. Retain interaction tests for editing, local undo, composition, save, cancel, expansion, and focus return.
- Compatibility or migration impact: Additive optional projection input and UI adapter change only. Existing callers keep 1.0 behavior by default. No memo/source migration, persistence API, Rust core, revision, history, undo, task hierarchy, or saved data changes.
- Requested authorization: Authorize creation and lock of `task-memo-live-markdown` 1.1 and the narrowly scoped projector option, editor-theme, CSS, and additive test changes described above.
- Authorization: authorized by the user's explicit request on 2026-08-30 to remove the typing highlight, support dark theme, and stop showing the original Markdown syntax.
